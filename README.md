# FinTrack – Personal Finance & Expense Analytics Platform

MERN stack (MongoDB, Express, React, Node.js) college lab project.

The application lives in the [`fintrack/`](fintrack/) folder. See **[fintrack/README.md](fintrack/README.md)** for features, setup, API reference, deployment steps and the CAS experiment mapping.

```
fintrack/
├── client/   React frontend (Vite)  -> deploy on Vercel (root directory: fintrack/client)
└── server/   Express REST API       -> deploy on Render (root directory: fintrack/server)
render.yaml   Render blueprint for the backend
```
